────────────────────────────────────────────────────────────────────────────────
1. COMMENT STRUCTURE
────────────────────────────────────────────────────────────────────────────────

  Full format:    PREFIX...ACCOUNT_PHASECODE + PHASE_NUMBER
  Short format:   PREFIX...ACCOUNT_PHASE (no number)

  Examples:
    MFFU...60076_FD1       → MyFundedFutures  | account 60076 | Funded Phase 1
    V2-...4610_CH2         → Topstep          | account 4610  | Challenge Phase 2
    FNFT...G8326_CH1       → FundedNext       | account G8326 | Challenge Phase 1
    AFAD...12345_FD2       → Alpha Futures    | account 12345 | Funded Phase 2
    TDFY...67890_FA        → Tradeify         | account 67890 | Farming
    ELTD...11111_FD1       → TradeDay         | account 11111 | Funded Phase 1

  The parser regex:
    ^([A-Z0-9\-]+)[^A-Z0-9]+([A-Z0-9]+)_(CH|FD|DD|FA)(\d+)?$


────────────────────────────────────────────────────────────────────────────────
2. PREFIX → PROP FIRM MAPPING
────────────────────────────────────────────────────────────────────────────────

  PREFIX    PROP FIRM              VALIDATION KEYWORDS (in "Prop Firm" column)
  ────────  ─────────────────────  ─────────────────────────────────────────────
  MFFU      My Funded Futures      MYFUNDED, MFFU, MY FUNDED
  V2-       Topstep                TOPSTEP, TOP STEP, V2
  FNFT      FundedNext             FUNDEDNEXT, FUNDED NEXT, FNFT
  AFAD      Alpha Futures          ALPHA, AFAD
  TDFY      Tradeify               TRADEIFY, TDFY
  ELTD      TradeDay               TRADEDAY, ELTD
  TDF       TradeDay / Tradeify    TRADEDAY, TDF, TRADEIFY
  FTDF      TradeDay / Tradeify    TRADEDAY, TDF, TRADEIFY

  Notes:
  - TDF and FTDF are shared between TradeDay and Tradeify.
    The actual firm is confirmed from the "Prop Firm" column in the sheet.
  - Double Dip firms: My Funded Futures, MFF, Topstep, TopstepX
    (these allow DD phase codes)


────────────────────────────────────────────────────────────────────────────────
3. ACCOUNT NUMBER MATCHING
────────────────────────────────────────────────────────────────────────────────

  MFFU (full account in MT5):
    Raw:       MFFUEVSTP326057008
    Signature: first 4 + last 4  →  mffu7008
    Matches:   Account # / Account #.1 in sheet (last 4-5 digits)

  FNFT (truncated in MT5):
    Raw:       FNFT...59574
    Signature: prefix(4) + suffix  →  fnft59574
    Account #  can start with a letter (e.g. G8326)

  Topstep (V2-):
    Raw:       V2-4610
    Matching:  Relaxed 4-digit match (last 4 digits)
    e.g.       V2-9889  matches  64959889  (last 4 = 9889)

  General rule:
    Phase   CH     → match against  "Account #"   column
    Phase   FD/DD/FA → match against  "Account #.1" column


────────────────────────────────────────────────────────────────────────────────
4. PHASE CODE → SHEET FIELD MAPPING
────────────────────────────────────────────────────────────────────────────────

  ── CH (Challenge) ──────────────────────────────────────────────────────────

    Phase Code   Sheet Field
    ──────────   ──────────────────
    CH1          Hedge Result 1
    CH2          Hedge Result 2
    CH3          Hedge Result 3
    CH4          Hedge Result 4
    CH5          Hedge Result 5

    All firms use the same CH mapping.
    CH uses "Account #" (not "Account #.1") for matching.


  ── FD (Funded) — MFFU ONLY (starts at FD0) ────────────────────────────────

    Phase Code   Sheet Field
    ──────────   ──────────────────
    FD0          Hedge Result 1.1
    FD1          Hedge Result 2.1
    FD2          Hedge Result 3.1
    FD3          Hedge Result 4.1
    FD4          Hedge Result 5.1
    ...          (continues)

    MFFU is identified by account number starting with "MFFU".
    MFFU uses FD0 as its first funded phase (offset +1 vs other firms).


  ── FD (Funded) — ALL OTHER FIRMS (starts at FD1) ──────────────────────────

    Phase Code   Sheet Field
    ──────────   ──────────────────
    FD0          Hedge Result 1.1  (rare/legacy — treated same as FD1)
    FD1          Hedge Result 1.1
    FD2          Hedge Result 2.1
    FD3          Hedge Result 3.1
    FD4          Hedge Result 4.1
    FD5          Hedge Result 5.1
    ...          (continues)

    Firms: Topstep, FundedNext, Alpha Futures, Tradeify, TradeDay


  ── DD (Double Dip) ─────────────────────────────────────────────────────────

    Phase Code   Sheet Field
    ──────────   ──────────────────
    DD1          Hedge Result 1.1
    DD2          Hedge Result 2.1
    DD3          Hedge Result 3.1
    DD4          Hedge Result 4.1

    Eligible firms: My Funded Futures, MFF, Topstep, TopstepX
    DD uses "Account #.1" for matching.


  ── FA (Farming) ────────────────────────────────────────────────────────────

    FA does NOT have a fixed numbered field.
    It dynamically fills the next available Hedge Day slot (1–50).

    Logic:
      1. Check if a Hedge Day slot already has the same date → reuse it
      2. Find first slot where both "Hedge Day N" and "_Hedge Day N Date"
         are empty → write to that slot
      3. Fallback: write to "Hedge Day 1" if all 50 slots are full

    Sheet fields:
      Hedge Day 1  →  Hedge Day 50    (profit values)
      _Hedge Day 1 Date  →  _Hedge Day 50 Date  (hidden date tracking)

    FA uses "Account #.1" for matching.


────────────────────────────────────────────────────────────────────────────────
5. HEDGE NET CALCULATION
────────────────────────────────────────────────────────────────────────────────

  Hedge Net.1 =
      SUM(Payouts)
    + SUM(Funded results: Hedge Result 1.1 … 5.1)
    + SUM(Phase 1 results: Hedge Result 1 … 5)
    - Fee
    - Activation Fee
    + SUM(Hedge Day 1 … Hedge Day 50)   ← FA farming days
